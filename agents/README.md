# AgencyOS Agents

Planned specialized agents:

- **Scout** — discover local service businesses.
- **Researcher** — build the permanent business intelligence profile.
- **Auditor** — evaluate the current website and digital presence.
- **Designer** — create the prospect website concept.
- **Copywriter** — write site and outreach copy.
- **Outreach** — draft and eventually send personalized outreach after approval gates.
- **Builder** — use Claude Code to build production websites after a client purchases.
- **QA** — test production sites before client review and launch.
- **SEO** — optimize local SEO and technical SEO.
- **Analyst** — measure acquisition, conversion, revenue, and operational performance.

Automation should begin with human approval gates and become progressively more autonomous as the workflows prove reliable.
